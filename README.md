Core machine learning algorithms and neural networks implemented from first principles using Python and PyTorch.


## 📌 Overview

This repository contains implementations of core machine learning and neural network concepts developed during my Master’s studies in Intelligent Field Robotic Systems (IFRoS).

The objective is to build a strong understanding of learning algorithms from first principles — starting with gradient descent and classical machine learning models, and progressing toward fully connected neural networks using PyTorch.

This work supports my focus in robotics, perception, and autonomous systems, where data-driven methods are increasingly essential.

---

## 🎯 Purpose

As a robotics-focused engineer, I believe understanding the mathematical foundations behind learning algorithms is essential. This repository reflects that approach — building and analyzing models step by step rather than relying only on high-level abstractions.

It serves as a technical foundation for future work in perception, SLAM, and intelligent robotic systems.

---

## 📚 Contents

### 📉 Gradient Descent for Linear Regression

Implementation of linear regression optimized using gradient descent.
Includes visualization of cost convergence and learning rate analysis.

### 🔎 Classification Fundamentals

Exploration of supervised classification problems, decision boundaries, and model behavior.

### 📊 Evaluation Metrics

Implementation and comparison of:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

Focus on understanding correct model evaluation and limitations of accuracy.

### 🌳 Decision Trees

Construction and analysis of decision tree models, including feature selection and overfitting considerations.

### 🔬 Fully Connected Neural Networks (PyTorch)

Two-part implementation covering:

* Network architecture definition
* Forward propagation
* Loss computation
* Backpropagation
* Training loop implementation
* Performance tracking

Serves as a foundation before moving toward more advanced deep learning models.
